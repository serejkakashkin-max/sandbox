# Сертификаты GigaChat

Поместите в этот каталог три локальных файла:

- `ca.pem` — корневой сертификат;
- `tls.pem` — клиентский сертификат;
- `tls.key` — приватный клиентский ключ.

Итоговые пути:

```text
TA\certs\ca.pem
TA\certs\tls.pem
TA\certs\tls.key
```

PEM-файлы и ключ исключены из Git. Не вставляйте содержимое `tls.key` в исходный код, логи, переписку или документацию.

Если приватный ключ зашифрован паролем, перед запуском приложения задайте переменную окружения `GIGACHAT_KEY_FILE_PASSWORD`. Сохранять пароль в проекте не нужно.
