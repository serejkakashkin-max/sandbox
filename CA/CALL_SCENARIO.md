# Сценарий «Звонок»

Сценарий определяется по `taskTypeCode=CALLING` в `SBER_CRM_GET_TASK_DETAIL` или по целевому ответу `VOICE360_CHECK_TRANSCRIPTION` для указанного ID.

- Ответ VOICE360 ожидается в виде `{"data":{"<ID>":true|false}}`.
- `factStartDate` берётся из карточки CALLING как есть; если там уже `+03:00`, дополнительные три часа не прибавляются.
- Если найден хотя бы один ответ `true`, рекомендуется перепроверить транскрибацию звонка, но сохраняется возможность сформировать ЗПИ.
- При нескольких разных `factStartDate`, которые нельзя однозначно связать с нужным звонком, приложение не подставляет случайную дату и не формирует ЗПИ до уточнения логов.
- Явные признаки встречи для целевого ID имеют приоритет над посторонней карточкой CALLING, чтобы новый сценарий не перехватывал существующую логику встречи.
